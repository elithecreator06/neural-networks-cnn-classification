# Neural Networks & CNN Classification

This project pairs a feedforward neural network implemented from first principles with an image classifier trained on the CIFAR-10 dataset.

## Notebook

`neural-network-and-cifar10-cnn.ipynb` contains:

- A feedforward neural network with manual forward propagation and backpropagation.
- A Keras convolutional neural network for CIFAR-10 image classification.

After 10 training epochs, the CNN achieved **68.3% test accuracy** and a **0.682 weighted F1 score**.

## Run it

Open the notebook in Google Colab or Jupyter and run the cells in order. CIFAR-10 downloads automatically through Keras; a GPU-enabled Colab runtime will speed up training.
